# 真实实测与循环账本口径

## 真实性

由本人提供至少三次做过同类任务的时间、材料/输出位置、重复步骤；时间可大致回忆，但明确标记“回忆”。不得把三份模拟材料或三次脚本运行当成做过三次科研工作。

最近一次真实任务记录研究问题、原始输入、预期小节、操作日志/真实截图。截图从真实操作取得，不绘制仿终端图片冒充记录。可直接使用原样终端输出，并补充真实结果图表。

## 测量口径

- 总耗时：从读取材料到形成可供导师审阅版本，含人工检查与修改。脚本耗时仅作子项。
- 基线：真实历史日志；缺失时另做一次无本 Skill 的对照，并标记“事后重测”，不要称为历史用时。重复任务的熟悉效应须披露。
- 错误：人工按同一标准标注数值错、证据不支持、无依据解释；机械失败数单独统计，不能混为科学错误数。
- 主要论断证据覆盖率：由研究者先划定主要论断集合，再计算有足够证据支持的条数/总数；脚本登记条数不等于覆盖率。
- 未测量的单元格写“未测量”，不填零，不给提效百分比。

## 开环与结案

先记录基线、目标、预算和允许杠杆，再执行。建议最多两轮修订，只改一个主要规则以便归因。成功标准：机械核验通过且主要语义疑点均已处理/明确保留人工裁决。缺输入、预算耗尽、度量口径失效时停止并记录原因；重新开环重新记账。

允许调整：证据定位、论断限定、写作组织、核验脚本的实际缺陷。

禁止调整：原始数据、对照条件、事后挑选有利实验、为通过检查放宽容限而不解释。
